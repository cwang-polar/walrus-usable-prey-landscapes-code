# Revision result summaries

This directory contains compact, non-coordinate result summaries supporting the
new analyses added during revision. Raw observations, station coordinates,
gridded surfaces, and cell-level cross-validation predictions are not included.

## Internal ice-accessibility sensitivity

- `ice_internal_parameter_scenario_definitions.csv`: the baseline and five
  targeted alternative parameterizations reported in Appendix S1: Table S5.
- `ice_internal_parameter_key_results.csv`: functional ceiling, mean
  minimum-area inflation, mean ice accessibility, and accessibility Gini for
  six scenarios across eight focal site-interval combinations (Appendix S1:
  Table S6).
- `ice_internal_parameter_key_window_ranges.csv`: scenario ranges summarized
  by focal site and interval and used for main-text reporting.
- `ice_internal_parameter_cplex_curve_points.csv`: all pure-reference and
  ice-adjusted CPLEX curve points used to calculate mean minimum-area inflation.

The full surface-building and optimization workflow is implemented in
`scripts/08_ice_internal_parameter_surfaces.py` and
`scripts/09_ice_internal_parameter_optimization.py`.

## Kriging cross-validation

- `kriging_loocv_taxon_summary.csv`: taxon-specific validation statistics for
  every site and five-year interval.
- `kriging_loocv_table_s7.csv`: taxon-specific and summed-prey statistics
  reported in Appendix S1: Table S7.

Cell-level predictions are generated by
`scripts/07_kriging_leave_one_grid_cell_out.py` when the processed input data
are available but are intentionally not included in this peer-review repository.
